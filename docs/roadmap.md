# Roadmap

## Phase 1 - MVP: brushes + erasers + layers + blend modes + themes
Features: pencil/pen/ink/marker/airbrush/watercolor/oil/charcoal/pastel/texture/pattern/scatter brushes; custom brush engine; pressure/tilt/velocity; stabilizer; symmetry; presets; import/export; erasers; raster/vector/text/3D/ref/group layers; blend modes; opacity/lock/hide/alpha lock/clipping/masks; filter layers (stubs); undo/redo; drag reorder; themes.

## Phase 2 - Animation timeline
Frame-by-frame cels, keyframes, tweening, onion skinning, camera layer, playback, export GIF/MP4/PNG/sprite sheet.

## Phase 3 - Sound editing
Multi-track audio, recording, waveforms, clip editing, fades/envelopes, effects, master bus, mixer, lip-sync, beat detection, sound library, synth, audio-driven animation, physics sound hooks, sync check.

## Phase 4 - 3D viewport
Mesh modeling, materials, camera, rendering.

## Phase 5 - Physics
Rigid/soft/cloth/particles, collisions, gravity/wind, bake.

## Phase 6 - 3D drawing
Grease pencil, 2.5D parallax, sketch-to-3D.
