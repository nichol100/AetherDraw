# AetherDraw

A creative workspace that combines 2D, 2.5D and 3D art, drawing and animation
in one application. Open source (MIT). Built with Rust.

## Status

Phase 1 scaffold: window, canvas, basic brush dot, layers, blend modes, themes.
Many modules are stubs for later phases (animation, audio, 3D, physics).

## Build

See `docs/dependencies.md` for per-OS dependency installation.

### Linux
```bash
./build_linux.sh
```

### Windows (PowerShell)
```powershell
./build_windows.ps1
```

## Run
```bash
cargo run
```
